title: 在胡风纪念馆的一些感想
---

当久久地目不转睛地望着深邃的苍穹，不知何故心灵就感到孤独。天上的星星，几千年来注视着人间。无边无际的苍穹和烟云，淡漠地注视着人短促的生命。​当你和它们相对而视，并努力去思索他们的意义时，在坟墓中等待我们每一个人的孤独之感就来到了心头。  

<div style="text-align:right">——契诃夫《草原》</div>

笔者近期回家，听说胡风纪念馆对外开放了，离家比较近，于是去参观了一下。纪念馆在一栋二层的小楼内，在二楼。拾梯而上，在楼梯拐角处赫然写着“文人风骨”四个大字。游览其中，“风骨”一词亦多次出现。笔者浅薄，初见“风骨”二字，觉得无非是后世在粉饰其人其事罢了，然而越后来越发觉得胡风生平堪称风骨二字，越发觉得自己见识之浅薄，境界之渺小。于是写此文，一为纪，一为志。  

纪念馆由左右两个纪念堂组成。右侧的纪念堂文字居多，以时间线详述胡风生平。左侧的纪念堂主要以照片为主，介绍胡风生平的一些重要节点，以及胡风本人的一些作品。笔者方知胡风原来是笔名，原名叫张光人。笔者看到胡风小时候、青年、中年以及老年的照片，虽然身躯逐渐老去，眼神却是纵其一生而未变。应该如何描述呢？那是一种以笔者当下的状态不敢与之对视的眼神，哪怕是短暂的注视也会被之灼伤。在眼神中可以看到斗志和和善两种感情，如果说眼神是一直不变的话，那变化的是这两种感情的比例了。  

如果只是看胡风的眼神，似乎年轻的时候充满斗志，晚年更多流露一些和善。然而阅读他的诗，感受却是相反。笔者摘抄了几首：  
```
我从田间来
蒙着满脸的灰尘
——望望这喧嚣的世界
不自由地怯生生

我从田间来
穿着一身的老布衣
——在罗绮丛中走过
留下些泥土的气味

我从田间来
心想再听不见哀音
——才踏进这外边的世界
声声的苦叫刺痛了我的心

我从田间来
远别了慈祥的笑脸
——身儿在这里奔驰
心儿在那里盘旋

我从田间来
带着赤心一颗
——遇着新奇的事儿
要印上花纹朵朵

我从田间来
抱着热血满腔
——叫我洒向何处呢，
对着无际的苍茫？……
```
写这首诗胡风正值23岁，应该是要长久离开故乡奔赴他乡去了。从字里行间可以感受到对故乡的眷念，和对前途未卜的忐忑。胡风晚年遭逢不幸，1955年被捕入狱，1978年释放，去世之后才彻底平反。  

```
竟在囚房度岁时，奇冤如梦命如丝
空中悉索听归鸟，眼里朦胧望圣旗
昨友今仇何取证，倾家负党忍吟诗
廿年点滴成灰烬，俯首无言见黑衣
```
这首诗写于1955年除夕，彼时胡风刚下狱当年。此时的诗中，包含着命运急转直下的惊恐，和友人反目的怨恨。  
```
不到黄河不畅怀，终知假往始真来
难堪士路空文苑，莫奈官场大戏台
夺理有条挥巨棒，装情无泪奠三杯
韩康药店今何在？屡将招牌倒又开
```
这首诗写于1966年，此时胡风已在狱中度过11年了。此时惊恐和怨恨已不可见，“莫奈官场大戏台”倒是有些“看透了”、“世界只是个草台班子”的通透。  

```
龙鳞披过刮蛇鳞，哪怕腥粘满手尘
敢是敢非真待友，装忠装顺假称臣
丢他粉彩无聊脸，还我金刚不坏身
拖却南冠长啸去，科头濯足大江滨
```

这首诗是胡风出狱之后，写给好友萧军的。此时胡风出狱但尚未平反，但诗风已经变了，变得凌厉了。完全不像一个刚出狱看透一切“活着就好”的老头，这让笔者想到伍子胥，被人问为何如此执着时，伍子胥回答“吾日暮途远”。笔者猜想出狱后的胡风觉得来日无多，而所求甚大，因此变得更为凌厉。  

观看胡风的一生，少时离乡读书，与军阀斗争，参加抗战， 参与新中国文化建设，下狱之后又被平反。一生可谓波澜壮阔，跌宕起伏。游览中，笔者脑海闪现过一个问题：“为什么叫胡风呢?”，一个答案直接着蹦入“越鸟巢南枝，胡马依北风”。或许无论是读书还是斗争，抗战还是解放，胡风自始至终都对故乡怀一种眷恋之情。胡风一生追求自由的文化、重视个性的表达，无论是哪种境遇，始终不变，这大概就是“文人风骨”的诠释吧。  

笔者试想，如果在纪念馆之前，被人问“如何看待风骨”，笔者大概率语无伦次、惶恐尴尬。“风骨”一词，笔者已经很久没有看到，也没有在周围环境中听到，心态上已经堕落到“谈论风骨不过是文过饰非而已”。在纪念馆之前，笔者觉得自己碌碌于琐事太久了，已经记不起来从何时开始每月计算着卡里的数字，盯着二线城市郊区房子的首付，按时打入贷款。笔者远离“风骨”久矣，让笔者感到羞愧的是，在工作完成之余，在夜深人静的时候，在还完贷款略有盈余的时候，想着地只是收入更多，也没有离“风骨”近一点。然而笔者坚持认为，“风骨”依然必不可少，是静坐观心时的慰藉，是陷入俗世中的救赎，是挣断锁链时的升华。君子藏器于身，待时而动，其中的器就有“风骨”的成分吧，哪怕周围环境对之三缄其口，但君子之行，却时刻提醒锻炼自己，以待有时可以挺身而出。  

普京在21世纪之交竞选总统时，有记者发难“你是否是苏联共产党员”，普京答“我自始至终都是苏联共产党员，苏共不在了，我就把党证放在抽屉里”。希望假以时日，笔者也可以这样说“我自始至终都是一个崇尚风骨的人，众人都避之不及时，我就把他藏在自己心里”。
