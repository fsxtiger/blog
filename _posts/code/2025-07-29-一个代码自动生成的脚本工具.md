笔者参与了一段时间业务开发，也就是为同行戏谑的“CRUD”。这样的工作，之所以令人厌倦，笔者体会原因之一是存在一些重复性工作。而且这些工作还容易出错，一不小心就会给后续的调试带来困扰。笔者开发了一个脚本工具，根据业务接口定义，自动生成绝大部分的重复性代码。笔者在最近的两个版本迭代中，都使用脚本工具来辅助开发，效果比较理想。笔者首先介绍业务开发涉及的技术栈和服务架构，然后介绍脚本实现方案。  

笔者业务开发采用的是经典的技术栈：java + springboot + mapstruct + grpc + mybatis。服务架构也比较常见，一个面向用户的Api层，和若干维护各自业务的下游服务。外部请求再传递给一个或几个下游服务，然后在聚合层做一些业务处理返回给用户。如果读者的业务架构和技术栈也是如此，脚本工具或许可以为你所用。服务架构如下所示：

以开发一个最常见的列表接口为例，开发在真正进行业务处理之外，还需要做以下笔者称之为重复性工作的工作：  

**Controller层**
```
    @ApiOperation("课程审核列表")
    @PostMapping("/list")
    public ResultWrapper<PageResultWrapper<CourseAuditVO>> courseList(@Valid @RequestBody AuditQueryParam auditQueryParam) {
        log.info("audit course list, param = {}", auditQueryParam);
        return ResultWrapper.success(auditCourseService.courseList(auditQueryParam));
    }
```
**Service层**
```
public interface AuditCourseService {
    PageResultWrapper<CourseAuditVO> courseList(AuditQueryParam auditQueryParam);
}
```
**Service实现层**
```
@Service
public class AuditCourseServiceImpl implements AuditCourseService {
    @Resource
    private RemoteComplexGrpcService remoteComplexService;
    @Resource
    private AuditCourseConvert auditCourseConvert;
    
    @Override
    public PageResultWrapper<CourseAuditVO> courseList(AuditQueryParam auditQueryParam) {
        AuditQueryModel auditQueryModel = auditCourseConvert.paramToModel(auditQueryParam);
        CourseAuditPageDTO courseAuditPageDTO = remoteComplexService.courseList(auditQueryModel);

        PageResultWrapper<CourseAuditVO> pageResultWrapper = new PageResultWrapper<>(auditQueryParam);
        pageResultWrapper.setTotal(courseAuditPageDTO.getTotal());
        pageResultWrapper.setRecords(auditCourseConvert.dtoToVOs(courseAuditPageDTO.getCourseAuditDTOsList()));

        return pageResultWrapper;
    }
}
```

笔者发现，开发人员根据需求定义好接口之后，上述代码都可以根据接口“推导”出来。比如Service接口层，方法名、形式参数和接口方法一样，返回参数只需简单去一下封装即可。再比如Service实现层，绝大部分逻辑是，先将和前端交互的VO对象，转换成下游交互的DTO对象，然后调用相应的下游接口。笔者使用Freemaker技术，将每层代码抽象成相应的ftl模版，脚本启动时通过解析接口参数来生成模版中的变量。以Service实现层为例，ftl模版文档如下：
```
package cn.golingo.glep.education.provider.service.impl;
<#assign uncapitalize_name = name?substring(0, 1)?lower_case + name?substring(1)>
<#list imports as import>
import ${import};
</#list>

/**
 * @author **.*
 * @date ${.now?string("yyyy/MM/dd")}
 */
@Service
public class ${name}ServiceImpl implements ${name}Service {
    @Resource
    private Remote${serviceName}Service remote${serviceName}Service;
    @Resource
    private ${name}Convert ${uncapitalize_name}Convert;


    <#list methods as method>
    @Override
    public ${method.returnValue} ${method.name}(${method.param}) {
        ${method.paramModel} = ${uncapitalize_name}Convert.paramToModel(${method.param});
        remote${serviceName}Service.${method.name}(${method.paramModel});
    <#if method.returnValue != 'void'>
        return null;
    </#if>
    }
    </#list>
}
```

package cn.golingo.glep.education.provider.service.impl;

 * @author **.*

@Service

    @Resource

        return null;
    }
}
