title: 从蝉声说起
---
夏日傍晚，与妻子在公园漫步。蝉声四起，空旷少人的公园显得更加寂静了。妻子打趣我来一首有关蝉的诗，率先映入我脑海的是骆宾王的《狱中咏蝉》：

```
西陆蝉声唱，南冠客思侵
那堪玄鬓影，来对白头吟
露重飞难进，风多响易沉
无人信高洁，谁为表予心
```

当讲到“那堪玄鬓影，来对白头吟”的时候，一时语塞，不知该如何翻译是好。查看网上的译文，几乎都是直译，看完似懂非懂。于是笔者试着自己翻译一下：
```
   在这深秋的夜晚，狱窗外传来阵阵蝉虫的鸣叫声。想想我这一生，戎马倥偬，
鞍马劳顿，好多年都没有回去了，想必这个时候故乡的蝉也在鸣唱吧！
   望着墙上自己的影子，正当壮年却满头白发。也罢，蝉兄，不妨进来咱们对一
对《白头吟》怎么样？ 
   蝉兄你为什么还不进来呢，是因为露水太重，让你无法展翅，还是这秋风太大，
连你的声音也逐渐被淹没，越来越听不见了。
   其实我何尝不是和你一样，身处如今这世上，人们纷纷攀附当权，那些高风亮
节的人，谁还会听他们的忠忱之言呢。那我赴死之后，我对李唐的一片忠心，估计
就更没人知晓了。
```

当前的很多翻译，采用逐字翻译然后连成句的方式，或者为了准确性，深抠几个字的含义。笔者以为大可不必。笔者坚持认为，像诗歌这类怡情为主的作品，翻译首先应讲究以美为主，甚至为此牺牲一部分真实含义也在所不惜。另外，诗歌讲究“五言七律”，受字数限制，因此上下句之间必然存在“留白”，这些“留白”正是译者可以充分发挥之处，以让整首诗的感情更为饱满。  

以我喜欢的一句诗为例，“劝君更近一杯酒，西出阳关无故人”。笔者看到最“雷人”的一个翻译是：“劝您再干了这一杯美酒，等你从阳关出使回来我估计都不在世上了”。为什么要这么翻译呢，因为译者认为长安在阳关的西边，因此“西出阳关”是从出使完毕从阳关回到长安，加之长安到安西千里之遥，要穿过茫茫大漠戈壁，所以等元二回来的时候诗人觉得自己大概率已经去世了。笔者当然无法确认王维在写这首诗的时候是不是真这么想，但是如此翻译实在伤感有余，美感不足。因此笔者给人翻译都是这样：
```
兄弟，干了这一杯还要再来一杯，常言道“衣不如新，人不如故”，你这次出使安西，
怕是不会遇到像咱俩这样开心痛快喝酒的人了。
```
唐朝诗人中以“李杜”名声最盛，不过笔者更喜欢王维。有两方面的原因。一方面欣赏王维的处世之风，兼有出世入世。一面为官报国，出使过塞外—— “征蓬出汉塞，归雁入胡天”。一面修道唯心——“独坐幽篁里，弹琴复长啸” 。既没有迷恋官场而忘记初心，也没有一心求道而废弛公事。在这方面，李白、杜甫就逊色得多，两人都要安庇天下之志。李白一生所为官职都是些侍臣的角色，所幸生活还挺富足。杜甫就更悲惨了，安史之乱后刚当“御史”，没几天就不谙官场被免职，“亲朋无一字，老病有孤舟”，自身晚年都没有善终。  

王维的诗就不一样，不谈主观感受，只写客观细节，让读者从中去领略诗人的心境。比如描写自己僻居南山的诗，没有说自己如何惬意，以及如何山清水秀、云淡风轻，而是通过自己随机的一次出行和邂逅，让读者感受到诗人的安宁和闲适。  
```
中岁颇好道，晚家南山陲
兴来每独往，胜事空自知
行至水穷处，坐看云起时
偶然值林叟，谈笑无还期
```

王维写下这首诗不出人意料，但是有位不太出名的诗人常建写下一首与此诗极为神似的诗：
```
清晨入古寺，初日照高林
曲径通幽处，禅房花木深
山光悦鸟性，潭影空人心
万籁此都寂，但余钟磬音
```

偶然值林叟，但余钟磬音。在静中加入了动，没有丝毫破坏静，反而显得静更加悠远绵长。
